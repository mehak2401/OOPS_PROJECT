# OOPS Banner App
A Java-based project demonstrating the evolution of code from basic console output to an object-oriented, data-driven banner generator.

## 🛠 Features & Evolution
- **UC1:** Simple "OOPS" console output.
- **UC2:** Banner format using ASCII art (* and spaces).
- **UC3:** Modular refactoring using dedicated functions for each character.
- **UC4:** Encapsulation of patterns into a `BannerPattern` class.
- **UC5:** Data-driven design using `HashMap` for dynamic pattern lookups.

## 🚀 How to Run
1. Compile the app: `javac OOPSBannerApp.java`
2. Run the app: `java OOPSBannerApp`

## 📈 Concepts Covered
- Git Branching & Merging
- Java Class Structures & Main Method
- Functional Decomposition
- Java Collections (HashMap)
